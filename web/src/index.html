2D cut-out animation, natively on macOS.

PivotCut is a free, open-source 2D cut-out animation app for Apple Silicon, inspired by Pivot Animator. Build hierarchical character rigs, pose them on a thumbnail timeline, add 2.5D parallax layers and a virtual camera, then export straight to a PNG sequence or MP4.

Requires macOS on Apple Silicon. No account, no subscription, no telemetry.

Character Rigs

Hierarchical cut-out rigs

Assemble characters from transparent PNG parts with real forward kinematics — rotate a shoulder and the whole arm follows.

  • Parent/child bone hierarchy with pivots and attach points
  • Reusable Character Library — build once, pose everywhere
  • Reliable Undo/Redo on every editing action
  • AI Text-to-Animation to generate a first pass from a prompt
Timeline

Frame-by-frame timeline

A Pivot Animator-style thumbnail timeline, rendered live from your actual scene — drag to reorder, set FPS and per-project exposure.

  • Real, rendered thumbnails — not static placeholders
  • Drag-and-drop frame reordering
  • Optional Smooth Animation: spline easing between poses
  • Playback that respects FPS and exposure
Camera & Export

Virtual camera, parallax & export

A per-frame virtual camera and depth-based 2.5D parallax layers give your scenes real depth — then export straight to a PNG sequence or MP4.

  • Background/midground/foreground layers with parallax depth
  • Per-frame camera position & zoom
  • PNG sequence export — always available, no setup needed
  • MP4 (H.264) export via FFmpeg, when installed

How PivotCut works

1

Import your PNGs

2

3

FAQ

Common questions about PivotCut

Is PivotCut really free?

Yes. PivotCut is completely free to download and use, with no account, subscription or in-app purchases.

What are the system requirements?

macOS running on Apple Silicon. PivotCut is a native arm64 app built with PySide6 (Qt) and Pillow.

Do I need FFmpeg?

Only for MP4 export. PivotCut works fully without it — PNG sequence export, playback and every editing feature need no extra setup. Install FFmpeg with brew install ffmpeg if you want MP4 output.

Does PivotCut collect any data?

No. PivotCut runs entirely on your machine — your projects, PNGs and exports never leave your computer, unless you choose to use the optional AI Text-to-Animation feature with your own API key.

Is the source code available?

Yes — PivotCut's full source is on GitHub . Issues and pull requests are welcome.
